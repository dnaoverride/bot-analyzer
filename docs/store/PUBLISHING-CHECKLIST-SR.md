# Checklist za objavu (vlasnik)

1. Uključi 2-Step Verification na Google nalogu.
2. Registruj Chrome Web Store developer nalog; proveri aktuelnu cenu u Dashboard-u.
3. Postavi javni git repozitorijum (MIT) i HTTPS stranice za privacy/support (PLACEHOLDER dok nisu spremne).
4. Snimi 3–5 screenshotova 1280×800 sa sintetičkim podacima.
5. Pokreni `npm run package:store` i upload-uj `release/botanalyzer-*-chrome.zip`.
6. Proveri da `manifest.json` u ZIP-u nema `scripting`/`activeTab`.
7. Popuni listing, privacy, dozvole i reviewer instructions.
8. Počni sa Unlisted beta; proveri instalaciju i migraciju podataka.
9. Ne obećavaj datum ili ishod Google pregleda u README-u.
