# Chrome Web Store listing (draft)

**Name:** BotAnalyzer — Comment Pattern Review

## Short description (en)

Locally review comment patterns on TikTok and Instagram. Manual evidence, human review, report draft. No bot score.

## Short description (sr)

Lokalna analiza obrazaca u komentarima na TikToku i Instagramu. Ručni unos, pregled i nacrt prijave. Bez procenata „bot“.

## Detailed description (en)

BotAnalyzer helps you collect public comment examples, compare repeated text or similar avatars, and prepare a **human-reviewed** report for platform review. It does **not** claim accounts are bots, purchased, or coordinated with certainty. Political views and private profiles are not suspicion signals. All processing stays on your device. TikTok visible-comment capture is experimental and excluded from the Store manual build.

## Detailed description (sr)

BotAnalyzer pomaže da prikupite javne primere komentara, uporedite ponovljene tekstove ili slične avatare i pripremite **ručno pregledan** nacrt za proveru platforme. Ne tvrdi da su nalozi botovi, kupljeni ili koordinisani. Politika i privatni profil nisu signali sumnje. Obrada je lokalna. TikTok prikupljanje je eksperimentalno i nije u Store ručnom paketu.
